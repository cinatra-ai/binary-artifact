# Binary

The system home for files whose form could not be determined. It accepts `application/octet-stream` — bytes that no signature, no structure and no file name could type — and files them in the artifact library under a dedicated binary type, so a file of an unknown kind lands correctly typed instead of being refused or filed as something it is not.

Install from the Cinatra marketplace by searching for "Binary" and clicking **Add**. No credentials or configuration are required; the type is active immediately for all workspace members. Opening a binary file shows a download card: its name, its form and its size, with a download action whenever your access allows one. Nothing is previewed inline — the form is unknown, so a preview would be a guess, and the card never guesses.

## Works with

- Cinatra chat — attach a file of any unrecognized kind directly in a thread
- The artifact library — open any binary item to see what it is
- A review — the same download card draws on the review card

## Capabilities

- Accept `application/octet-stream` uploads as a dedicated artifact type
- Present the file name, its form and its size, with the download when it is available
- Never a blank view, never a guessed preview, and never an offer of a download that is not there
